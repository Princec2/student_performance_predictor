Student Performance Predictor 🎓

A machine learning project that predicts student performance based on academic indicators using Python, Streamlit, and scikit-learn.

📌 Project Overview

The Student Performance Predictor takes four inputs and generates a predicted final marks value. It demonstrates how machine learning can be used to build a simple, interactive prediction application for educational use cases.

✨ Features

- Predicts student performance from academic inputs.
- Accepts study hours, previous marks, attendance, and assignment score.
- Provides an interactive user interface using Streamlit.
- Uses a trained machine learning model for predictions.

🛠️ Technologies Used

- Python
- Streamlit
- scikit-learn
- Pandas (if used in the project)

📥 Input Features

- Study Hours
- Previous Marks
- Attendance
- Assignment Score

📂 Project Files

- "app.py" — Streamlit application interface.
- "student_prediction.py" — Prediction logic.
- "student_performance_model.pkl" — Saved machine learning model.

🚀 How to Run

1. Install Python on your system.

2. Clone or download this repository.

3. Open a terminal in the project folder.

4. Install the required libraries:
   
   pip install streamlit scikit-learn pandas

5. Start the application:
   
   streamlit run app.py
